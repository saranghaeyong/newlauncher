# Changelog

## 1.0.0 — Initial development build

- Create a native Java Android TV home activity.
- Add a dark, minimal interface with red accent and clock/date.
- Discover Leanback apps, with a launcher-activity fallback.
- Support D-pad navigation and launching apps with OK/Enter.
- Add release minification and resource shrinking.
- Add GitHub Actions release APK build and artifact upload.

This is the first development build. Device compatibility and final APK size still require CI and real-device verification.
